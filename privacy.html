EBP-SLP

Privacy Policy

Last updated: June 2026
EBP-SLP is designed from the ground up to protect patient privacy. We do not collect, store, or transmit any personal data -- yours or your patients'.

Who we are

EBP-SLP is a clinical reference and session planning application for licensed speech-language pathologists (SLPs). The app is developed and maintained by Abbey Rowe.

Questions about this policy can be directed to: info@ebpslpapp.com

What data we collect

We collect no personal data. EBP-SLP does not require account creation, login, or registration of any kind. We do not collect your name, email address, location, or any other personally identifying information.

What data is stored on your device

EBP-SLP stores the following data locally on your device only:

  • Your profile information (name, credentials, work setting) -- entered voluntarily and stored only on your device
  • App settings (default session length, display preferences)
  • Session plans you have saved to your caseload, identified by non-identifying labels you create
  • Session data you collect during clinical sessions (trial counts, accuracy rates, cue levels)
  • Onboarding completion status

None of this data is transmitted to any server, shared with any third party, or backed up to any cloud service. It exists only on the device where the app is installed. If you delete the app, all locally stored data is permanently deleted.

WARNING: EBP-SLP is not HIPAA-compliant software. Do not enter any Protected Health Information (PHI) -- including patient names, dates of birth, diagnosis codes, or any other identifying information -- into this app. Patient labels must be non-identifying.

AI-generated session plans

When you generate a session plan, a request is sent to a secure proxy server, which forwards it to Anthropic's Claude API. This request contains only the clinical parameters you select (diagnosis area, severity, session length, materials, and goals) -- no patient names, no identifying information, and no PHI of any kind.

Anthropic's use of data sent through their API is governed by Anthropic's Privacy Policy. We do not store the content of these requests or the generated plans on any server.

Remote article content

EBP-SLP retrieves article content from a public GitHub repository. This request contains no user data -- it is a standard HTTPS request for a publicly available JSON file. No identifying information is transmitted.

Third-party services

EBP-SLP uses the following third-party services:

  • Anthropic Claude API -- for AI-generated session plans. Clinical parameters only; no PHI. See Anthropic's Privacy Policy.
  • GitHub -- for hosting article content. No user data transmitted. See GitHub's Privacy Statement.
  • Netlify -- for hosting the API proxy function. No user data is stored. See Netlify's Privacy Policy.

Analytics and tracking

EBP-SLP does not use any analytics, tracking, or advertising SDKs. We do not track app usage, session behavior, or in-app actions.

Children's privacy

EBP-SLP is intended for use by licensed healthcare professionals only. It is not directed at children under the age of 13, and we do not knowingly collect any information from children.

Changes to this policy

If we make material changes to this privacy policy, we will update the "Last updated" date at the top of this page. Continued use of the app after changes constitutes acceptance of the updated policy.
